IMAGE TO PDF BY PIYUSH — GITHUB PAGES STARTER

FILES
- index.html: your existing converter, with basic SEO metadata and a Privacy Policy link added.
- privacy.html: starter privacy policy. Review it and add a real contact email before publishing.

PUBLISH FROM ANDROID (GITHUB PAGES)
1. Download/extract this ZIP on your phone.
2. Open https://github.com in Chrome and sign in.
3. Create a PUBLIC repository named image-to-pdf-by-piyush.
4. In the repository, tap Add file > Upload files. Upload index.html and privacy.html (upload the files themselves, not the ZIP).
5. Commit the files to the main branch.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch; branch main; folder /(root); tap Save.
8. Wait for the Pages deployment. Your URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/image-to-pdf-by-piyush/
9. Replace YOUR-GITHUB-USERNAME with your exact GitHub username. Open the URL and test image selection, conversion, download, and privacy link.

IMPORTANT
- GitHub Pages websites are public. Never upload private files or secrets to the repository.
- The converter loads pdf-lib and JSZip from cdnjs, so users need internet access when the page first loads the libraries.
- This is static hosting; it does not need a backend for the current browser-based converter.
- Do not paste placeholder AdSense code or make up a publisher ID. After your site is live, check whether AdSense accepts the URL you are using, then add the exact verification/ad code supplied by AdSense. Approval is not guaranteed.
- A free GitHub Pages URL may not be eligible for direct AdSense signup/approval in the same way as a custom domain or supported host-partner subdomain. Check AdSense's current site-URL rules before relying on it for monetization. A custom domain may later be necessary.
- AdSense approval requires policy compliance and enough useful, original content; a working converter alone does not guarantee approval.
- After receiving your real publisher ID, follow Google's instructions before creating an ads.txt file. Do not publish a fake ads.txt entry.
- Do not place ads near controls in a way that encourages accidental clicks. Never click your own ads.
